# MAAI902_UAE_Complaint_Triage-Project
NLP triage for bank customer complaints: masks personal data, routes each complaint to one of 8 product teams with a fine-tuned DistilRoBERTa, and sends low-confidence cases to human review. Trained on real CFPB complaint narratives and aligned with CBUAE complaint-handling rules. 61% auto-routed at 94.9% accuracy.
